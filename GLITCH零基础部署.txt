🎉 最简单的免费部署 - Glitch（无需 GitHub！）

═══════════════════════════════════════════════════════════════

🚀 部署只需2步（3分钟搞定）：

───────────────────────────────────────────────────────────────

【第一步】打开 Glitch 并创建项目

   1. 🌐 打开浏览器，访问：
      https://glitch.com

   2. 🖱️ 点击右上角 "Sign In"
   
   3. 选择登录方式（任选一个）：
      - GitHub 账号登录
      - 邮箱注册登录（不用绑卡！）
      
   4. 登录后点击 "New Project"
   
   5. 选择 "Import from GitHub"
   
   6. 输入仓库地址：
      ❌ 如果你没有 GitHub仓库，跳过这步！
      
      ✅ 往下看第二步，手动创建更简单！

───────────────────────────────────────────────────────────────

【第一步 - 更简单的方式】

   1. 点击 "New Project"
   2. 选择 "hello-express" 模板（不用管它，后面会替换）
   3. 项目创建后，点击左边的 "Package.json"
   4. 删除里面所有内容

───────────────────────────────────────────────────────────────

【第二步】上传代码文件

   📁 你需要上传这3个文件到 Glitch：

   文件1: app.py
   文件2: requirements.txt  
   文件3: .env（手动创建）

   ─────────────────────────────────────────────────────────

   📝 手动创建 .env 文件（在 Glitch 里点击 "New File"）

   写入：
   FLASK_ENV=production
   SECRET_KEY=your-secret-key-change-this

   ─────────────────────────────────────────────────────────

   📝 替换 package.json 内容：

   {
     "name": "wordcloud",
     "version": "1.0.0",
     "description": "Interactive Word Cloud",
     "main": "app.py",
     "scripts": {
       "start": "python app.py"
     },
     "dependencies": {}
   }

   ─────────────────────────────────────────────────────────

   📝 删除其他不需要的文件

   只保留：
   ✅ app.py（从桌面复制过来）
   ✅ requirements.txt（从桌面复制过来）
   ✅ .env（手动创建）
   ✅ package.json（刚创建的）

   删除这些：
   ❌ public/index.html
   ❌ server.js
   ❌ README.md

───────────────────────────────────────────────────────────────

【第三步】Glitch 自动安装依赖

   ⏱️ Glitch 会自动运行：
   pip install -r requirements.txt

   等待1-2分钟，查看 Logs 确认安装成功

───────────────────────────────────────────────────────────────

【第四步】获得访问地址！

   ✅ 点击 "Preview" → "Preview in a new window"

   🌐 你的应用地址：
   https://xxxxx.glitch.me

═══════════════════════════════════════════════════════════════

💡 如果预览窗口显示错误：

   1. 点击左下角 "Logs"
   2. 查看错误信息
   3. 常见问题：
      - "No such file" → 检查文件是否都上传了
      - "Module not found" → 等待 pip install 完成
      - Port error → 修改 app.py 端口为 $PORT

   4. 修改 app.py 端口（在最下面找到）：
      app.run(debug=False, host='0.0.0.0', port=int(os.environ.get('PORT', 5000)))
