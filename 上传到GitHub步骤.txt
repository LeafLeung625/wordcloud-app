───────────────────────────────────────────────────────────────

【第一步】创建 GitHub 仓库

   1. 打开浏览器访问：https://github.com
   2. 登录 GitHub（没有账号先注册）
   3. 点击右上角「+」→「New repository」
   4. Repository name 填：wordcloud-app
   5. 选择「Public」
   6. 点击「Create repository」

───────────────────────────────────────────────────────────────

【第二步】上传文件

   1. 在 GitHub 仓库页面，点击「uploading an existing file」
   2. 打开「此电脑」→「桌面」→「词云应用_GitHub上传」文件夹
   3. 全选所有文件（Ctrl+A）
   4. 拖拽到 GitHub 上传区域
   5. 点击「Commit changes」

───────────────────────────────────────────────────────────────

【第三步】部署到 Railway（永久免费公网）

   2. 点击「Login」→「Login with GitHub」

   4. 搜索并选择「wordcloud-app」
   5. 等待 2-3 分钟自动部署完成
   6. 获得公网访问链接！
