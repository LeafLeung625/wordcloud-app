🚀 Render 部署指南（免费平台）

═══════════════════════════════════════════════════════════════

📋 部署步骤：

───────────────────────────────────────────────────────────────

【第一步】上传到 GitHub（已完成）

   1. 打开 https://github.com
   2. 创建新仓库：wordcloud-app
   3. 上传所有文件（包含新增的 render.yaml）
   4. 点击 "Commit changes"

───────────────────────────────────────────────────────────────

【第二步】注册 Render

   1. 打开：https://render.com
   2. 点击 "Get Started" 或 "Sign Up"
   3. 选择 "GitHub" 登录（推荐）
   4. 授权 GitHub 访问

───────────────────────────────────────────────────────────────

【第三步】创建 Web Service

   1. 点击 "New +" 按钮
   2. 选择 "Web Service"
   3. 在 "Connect a repository" 页面：
      - 找到 "Public Git repository"
      - 输入你的 GitHub 仓库地址：
        https://github.com/你的用户名/wordcloud-app
   4. 点击 "Next"

───────────────────────────────────────────────────────────────

【第四步】配置服务

   在配置页面填写：

   Name: wordcloud-app
   Region: Singapore（亚洲节点，访问快）
   Branch: main
   Runtime: Docker（选择这个）
   Instance Type: Free

   Build Command: （留空，使用 Dockerfile）
   Start Command: （留空，使用 Dockerfile）

   点击 "Create Web Service"

───────────────────────────────────────────────────────────────

【第五步】等待部署

   ⚙️ Render 会自动：
   1. 拉取代码
   2. 构建 Docker 镜像
   3. 部署应用

   ⏱️ 预计需要 2-5 分钟

───────────────────────────────────────────────────────────────

【第六步】获得访问地址

   ✅ 部署成功后，你会看到：
   
   Your site is live at:
   https://wordcloud-app.onrender.com

   🌐 这就是你的公网访问地址！

═══════════════════════════════════════════════════════════════

⚠️ 重要提示：

   • Render 免费版限制：
     - 每月 750 小时免费
     - 15 分钟无活动会休眠（首次访问后需等待唤醒）
     - 唤醒需要 30 秒左右

   • 如果需要永不休眠：
     - Railway 是不错的选择
     - 或者升级到付费版（约 $7/月）

═══════════════════════════════════════════════════════════════

🎉 部署成功后测试：

   🌐 主页：https://wordcloud-app.onrender.com/
   📊 词云：https://wordcloud-app.onrender.com/cloud

   1. 提交一些文字
   2. 等待 5 秒
   3. 查看词云自动刷新
