📋 部署只需5步（10分钟）：

───────────────────────────────────────────────────────────────

【第一步】注册 PythonAnywhere

   1. 🌐 打开：https://www.pythonanywhere.com
   2. 🖱️ 点击 "Sign up for a free account"
   3. 📧 选择 "Beginner" 免费版
   4. 📝 填写邮箱注册（不用绑卡！）
   5. 📧 邮箱验证

───────────────────────────────────────────────────────────────

【第二步】进入 Bash 控制台

   1. 登录后进入仪表盘
   2. 点击顶部的 "Bash" 或 "Console" → "Bash"
   3. 打开在线命令行

───────────────────────────────────────────────────────────────

【第三步】创建应用目录

   在 Bash 里输入：

   cd ~
   mkdir -p wordcloud
   cd wordcloud

───────────────────────────────────────────────────────────────

【第四步】上传代码文件

   📁 你需要上传 3 个文件到 PythonAnywhere：

   方法A - 在线上传（推荐）：
   1. 点击左侧 "Files"
   2. 进入 wordcloud 文件夹
   3. 点击 "Upload" 按钮
   4. 上传桌面的这些文件：
      - app.py
      - requirements.txt
      - config.py

   方法B - 用 wget 下载（如果有 GitHub）：
   在 Bash 里输入：
   git clone https://github.com/你的用户名/wordcloud-app.git

───────────────────────────────────────────────────────────────

【第五步】安装依赖

   在 Bash 里输入：

   cd ~/wordcloud
   pip install --user -r requirements.txt

   ⚠️ 如果提示权限问题，去掉 --user 参数：
   pip install -r requirements.txt

───────────────────────────────────────────────────────────────

【第六步】配置 Web 应用

   1. 点击顶部 "Web"
   2. 点击 "Add a new web app"
   3. 点击 "Manual configuration"
   4. 选择 Python 版本：Python 3.9 或 3.10
   5. 点击 "Next"

───────────────────────────────────────────────────────────────

【第七步】设置 WSGI 文件

   1. 在 Web 页面找到 "WSGI configuration file"
   2. 点击进入编辑
   3. 删除所有内容，替换为：

   import sys
   path = '/home/你的用户名/wordcloud'
   if path not in sys.path:
       sys.path.insert(0, path)

   from app import app as application

   ⚠️ 把"你的用户名"替换成你的 PythonAnywhere 用户名！

───────────────────────────────────────────────────────────────

【第八步】设置静态文件（可选）

   如果有静态文件，在 Web 页面找到：
   Static files: /static/

   URL: /static/
   Directory: /home/你的用户名/wordcloud/static

───────────────────────────────────────────────────────────────

【第九步】重载应用

   1. 点击绿色的 "Reload web app" 按钮
   2. 等待几秒钟

───────────────────────────────────────────────────────────────

【第十步】访问你的应用！

   🌐 在 Web 页面顶部，你会看到：
   https://你的用户名.pythonanywhere.com

   📊 词云页面：
   https://你的用户名.pythonanywhere.com/cloud
